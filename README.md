This project focuses on the design and development of a desktop To-Do List application using ElectronJS. The application helps users manage their daily tasks in an easy and organized way. Users can add new tasks, view their task list, mark tasks as completed, and delete tasks when necessary. HTML, CSS, and JavaScript are used to develop the user interface and handle the application’s functions. ElectronJS is used to run the application as a desktop program, while LocalStorage is used to save task information locally. This project provides practical knowledge of desktop application development and the use of ElectronJS with web technologies.
