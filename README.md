# To-Do List Desktop Application

 Project Summary

This project is a desktop To-Do List application developed using ElectronJS, HTML, CSS, and JavaScript. It helps users organize and manage their daily tasks easily.

The application allows users to add new tasks, view tasks, mark tasks as completed, and delete tasks. LocalStorage is used to save task information locally.

 Technologies Used
- ElectronJS
- HTML
- CSS
- JavaScript
- LocalStorage

 Project Purpose

The main purpose of this project is to learn desktop application development using ElectronJS and web technologies.

 How to Run

```bash
npm install
npm start
```
